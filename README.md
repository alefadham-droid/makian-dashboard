# makian-dashboard

پنل مدیریتی اختصاصی برای اپلیکیشن [makian.net](https://github.com/alefadham-droid/makian.net).  
این پنل امکان مشاهده، ویرایش و تحلیل داده‌های پروژه `makian.net` را از طریق فایل پشتیبان JSON فراهم می‌کند.

## ویژگی‌ها

- مشاهده لیست گزارش‌های روزانه.
- مشاهده و مدیریت سالن‌ها.
- مشاهده و حذف کاربران.
- خروجی و ورودی اطلاعات به صورت فایل JSON.

## نحوه استفاده

1. در پروژه [makian.net](https://github.com/alefadham-droid/makian.net)، از منوی "خروجی اطلاعات" یک فایل JSON دانلود کنید.
2. این فایل را در این پنل (صفحه اصلی) **وارد کنید**.
3. پس از اعمال تغییرات (مثلاً حذف یک گزارش قدیمی)، یک فایل JSON جدید **خارج کنید**.
4. این فایل جدید را در [makian.net](https://github.com/alefadham-droid/makian.net) **وارد کنید** تا تغییرات اعمال شود.

## فایل‌ها

- `index.html`: ساختار اصلی پنل.
- `admin-style.css`: استایل‌های ظاهری.
- `admin-script.js`: منطق کار با داده‌ها.

## نکات مهم

- این پنل مستقیماً به `makian.net` متصل نیست. برای استفاده، باید فایل پشتیبان JSON را از `makian.net` وارد کنید و پس از ویرایش، دوباره خروجی بگیرید و در `makian.net` وارد کنید.
- این پنل فقط امکان **مشاهده** و **حذف** اقلام را فراهم می‌کند. برای امکانات پیشرفته‌تر (مثل ویرایش یا افزودن)، نیاز به توسعه بیشتر دارد.
